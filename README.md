 ### Parking App

ParkNå . A mobile parking application designed to help users search for, view, manage, and create parking spaces in their area. The application utilizes various libraries and frameworks to deliver a seamless user experience. The project follows the principles of Clean Architecture, which emphasizes separation of concerns, making the codebase more maintainable, testable, and scalable.
